# Simple Voice Chat for Horizon (Native Mod)

Порт Simple Voice Chat для нативного клиента Minecraft на Rust — **Horizon**.
Поддерживает оригинальный сетевой протокол Simple Voice Chat 2.6.x (версия совместимости 20), благодаря чему полностью совместим с серверами Fabric/Forge/Paper/Spigot/Velocity/BungeeCord.

---

## Возможности

- **Качественный звук:** Встроенный кодек Opus (libopus) и нативный захват/воспроизведение аудио (`cpal`: Windows WASAPI, Linux ALSA/PulseAudio).
- **Режимы передачи:**
  * Push-to-Talk (рация) — клавиша по умолчанию: `~` (Grave Accent).
  * Голосовая активация с регулируемым порогом чувствительности.
- **Групповой войс-чат:**
  * Создание изолированных, открытых и стандартных групп.
  * Установка паролей на вход в группу.
- **Индивидуальная регулировка громкости игроков:**
  * Быстрый поиск игроков по никнейму.
  * Регулировка громкости от 0% до 200%.
  * Кнопка быстрого глушения (Mute/Unmute).
  * Постоянное сохранение настроек по уникальному UUID игрока в `config/simple_voice_chat/voice_chat.json`.
- **Индикация в реальном времени:**
  * Иконка микрофона и динамика в HUD.
  * Индикаторы говорения игроков в списке и в HUD группы.

## Установка через Horizon Launcher

### Способ 1: Прямая установка по ссылке с GitHub
1. В лаунчере Horizon перейдите на вкладку **«Моды»**.
2. В поле **«Добавить нативный мод с GitHub»** вставьте ссылку на этот репозиторий (или его релиз).
3. Нажмите **«Добавить с GitHub»**.
4. Лаунчер автоматически загрузит мод и скомпилирует его при следующем запуске игры!

### Способ 2: Ручная установка файла `.hmod`
1. Скачайте файл `simple_voice_chat.hmod` из раздела [Releases](../../releases).
2. Поместите его в папку модов Horizon:
   - Windows: `%APPDATA%\horizon\horizon-mods\simple_voice_chat.hmod`
   - Linux: `~/.config/horizon/horizon-mods/simple_voice_chat.hmod`
3. В лаунчере Horizon включите мод в списке и нажмите «Играть».
